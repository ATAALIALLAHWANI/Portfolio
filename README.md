# Ata Ali Alahawani — Portfolio

Personal portfolio site: https://ataaliallahwani.github.io/Portfolio

Static HTML/CSS with Font Awesome icons (no build step), deployed to GitHub Pages on every push to `main` via `.github/workflows/static.yml`.

- `index.html` — page content (hero, what I do, projects, contact)
- `style.css` — styles and responsive layout
- `assets/` — photo, CV (`Ata_ali.pdf`), `projects/` screenshots
